# CSDATA · CS2 饰品市场观察工具

把饰品异动、市场信号与大商库存放在同一个看板里。

CSDATA 面向关注 Counter-Strike 2 饰品市场的玩家与数据观察者，整理价格、求购、在售和公开库存的变化，帮助你从市场概览找到值得进一步查看的饰品和记录。

**[访问 CSDATA](https://cs2monitor.cn)** · [功能介绍](FEATURES.md) · [常见问题](FAQ.md)

> 本仓库用于介绍 CSDATA 网站，公开产品说明与使用指引。网站通过在线服务提供，应用源码未在此仓库发布。

## 你可以用它做什么

| 想了解的问题 | 在 CSDATA 中查看 |
| --- | --- |
| 最近市场变化集中在哪些时间、哪些品类？ | 首页异动趋势与板块异动排行 |
| 某件饰品的求购、在售或底价发生了什么变化？ | 饰品异动与历史记录 |
| 哪些饰品触发了值得进一步核对的条件？ | 规则信号与历史信号 |
| 监控范围内的大商库存出现了什么变化？ | 大商库存、变动记录与活跃排行 |
| 想持续观察自己关注的公开库存？ | 按账号权益使用自定义大商监控 |

各模块的开放范围、可查询时间和使用额度，以网站当前页面及账号权益为准。

## 从概览到明细

**先看趋势。** 在首页查看求购与在售变化的分布，再通过板块排行定位变化集中的饰品类型。

**再看记录。** 打开对应的饰品异动、信号或大商页面，结合日期、平台和具体数值查看上下文。

**最后核对。** 回到相关平台核对当前价格、挂单和库存状态，再做自己的判断。

网站提供桌面端与手机端布局，支持浅色和深色主题。初次使用可以从首页概览开始，再按需要查看历史明细。

## 开始使用

1. 打开 **[cs2monitor.cn](https://cs2monitor.cn)**，按照页面提示注册或登录。
2. 从首页了解近期趋势，进入感兴趣的模块查看记录。
3. 在帮助中心阅读指标说明，在个人中心查看当前权益及套餐信息。

基础版提供首页概览及部分预览；完整历史、详细信号、大商信息等内容按照账号权益开放。具体价格和配额请以站内展示为准。

## 读数据时需要知道

- **异动不等于成交。** 求购、在售数量变化是相邻有效采集之间的差异。
- **库存变化不等于买卖。** 公开库存快照的差异不能单独证明实际交易行为。
- **信号不等于结论。** 规则命中只是进一步检查的线索，不保证后续价格方向。

CSDATA 提供数据整理与观察工具，不提供交易撮合或收益保证。数据可能存在延迟、缺失或平台口径差异；服务规则以网站当前用户协议、隐私政策及免责声明为准。
